# Support keys used by references/css-rendering.md

Checked: 2026-09-23, against the research copies of MDN browser-compat-data 8.1.2 (build 2026-09-17, `raw/bcd.json`) and web-features (`raw/web-features.json`), and the fact-check reports `verify/05-css-rendering.verify.md`, `verify/06-js-event-loop-and-scheduling.verify.md` and `verify/01-critical-rendering-path.verify.md`. Target: Chromium only (Chrome and Edge). Other engines appear only through the Baseline column.
Rules tagged `baseline` need no row: `will-change` (Chrome 36), individual transforms (Chrome 104; high 2025-02-05), Web Animations incl. `commitStyles()`, `finished`, `getAnimations()`, `persist()` (Chrome 84; high 2023-03-16), size container queries (Chrome 105; high 2025-08-14), `:has()` (Chrome 105; high 2026-06-19), `prefers-reduced-motion` (Chrome 74), `filter` and `transform` (universal).

Facts that the rules state without a version (for §B, §C or §E, if the support.md writer wants them on record):

- `commitStyles()` without a fill ("end-point inclusive"): Chrome 144 (BCD `api.Animation.commitStyles.endpoint_inclusive_commitStyles`). CSS-17 keeps `fill: 'forwards'` until `commitStyles()`, so it works on any floor; the fill can go once the floor is 144 or later.
- `KeyframeEffect.iterationComposite`: not in Chrome (BCD). CSS-03 says so without a version.
- `interpolate-size` and `calc-size()`: Chrome 129, experimental, not Baseline (web-features). CSS-01 names them only in Avoid (they still run layout every frame).
- Size containers stopped applying layout containment ("weak containment") in Chrome 129 (BCD `css.properties.container-type.weak_containment`; CSSWG issue 10544). On older Chromium, a size container also contained layout. CSS-11 states the current behavior.
- `overscroll-behavior`: Chrome 63 partial, full from Chrome 144 (also applies to containers without scrollable overflow); web-features: not Baseline (Chrome 144, Firefox 150). CSS-23 is a one-line rule with no support tag.
- `text-wrap: balance`: Chrome 114; newly available (low 2024-05-13). Chromium balances only blocks of six lines or fewer. CSS-22.
- `overflow-anchor`: Chrome 56; newly available (low 2026-09-14, when Safari 27 added it). CSS-24.
- `image-rendering: pixelated`: Chrome 41; widely available (high 2024-04-05); unprefixed `crisp-edges` Chrome 148 (verify/05). CSS-25.
- `display` and `content-visibility` in exit keyframes: Chrome 116 (17-collections-batch-04, unchecked); `transition-behavior: allow-discrete`, `@starting-style` and transitionable `display`: Chrome 117 (BCD). CSS-26.
- Constructed stylesheets (`adoptedStyleSheets`): Chrome 73; widely available (high 2025-09-27). CSS-28.
- CSS scroll snap: Chrome 69; widely available. CSS-31.
- DevTools: the "CSS selector costs" insight (`SlowCSSSelector`) appears only when "Enable CSS selector stats" is on, so chrome-devtools-mcp traces probably lack it (14-devtools-mcp-and-webmcp.md, inference). CSS-12 asks the user to record once with the setting on.
- chrome-devtools-mcp `emulate` has no `prefers-reduced-motion` option (tool reference: cpuThrottlingRate, networkConditions, viewport, userAgent, colorScheme, geolocation, extraHttpHeaders). CSS-21 asks the user to turn on the OS setting.
