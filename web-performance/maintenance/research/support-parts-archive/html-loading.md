Facts that html-loading.md states without a version (for §B, §C, §E or §G, if the support.md writer wants them on record):

- 103 Early Hints: Chrome 103; Chrome accepts a 103 only over HTTP/2 or HTTP/3, only for navigation requests, only the first 103, and drops the hints on a cross-origin redirect; only cacheable resources can be preloaded from a 103, others are fetched twice (verify/02, verify/03, verify/04). HTML-24.
- HTTP/2 server push: disabled by default in Chrome 106 (verify/04). HTML-24 says "never".
- `<link rel="prerender">`: since Chrome 63 only a NoState Prefetch; deprecated and non-standard (verify/03, verify/04). HTML-19.
- `prerender_until_script`: origin trial Chrome 144–150, extended through 154; no intent to ship (verify/03, verify/04). HTML-19 Avoid; belongs in §G (watch list).
- `No-Vary-Search`: HTTP cache Chrome 141 desktop and Chrome 143 Android; speculation-rules prefetch 121, prerender 127 (verify/04, verify/16 group 03). HTML-19, HTML-26.
- `blocking="render"`: Chrome 105 (web-features `blocking-render`, limited). `<link rel="expect">`: Chrome 124, experimental in BCD (verify/01, verify/04). HTML-06.
- Preconnect: Chromium drops an unused preconnected socket after about 60 s (`kPreconnectIntervalSec = 60` in `net/socket/client_socket_pool_manager.cc`); used idle sockets stay 300 s (verify/02, 15-gaps-round-2). HTML-11.
- Preload: Chromium ignores `rel=preload` in `Link` headers on subresource responses (feature `kRestrictLinkHeaderOnSubresource`, enabled by default; network hints still work there). An unused preload logs a console warning 3 s after `load` (`kUnusedPreloadTimeout`) (verify/16 group 01). HTML-12.
- Chrome priorities (web.dev fetch-priority table): early CSS Highest (High with `fetchpriority="low"`); async and defer scripts Low; images Low, the first 5 large images Medium from Chrome 117; CSS whose `media` does not match Lowest and not fetched by the preload scanner (verify/01, verify/02, verify/04). HTML-05, HTML-08, HTML-09, HTML-12.
- Code cache (Chromium `v8_code_cache.cc`): the cache is produced on a load within 72 hours of the first (`kHotHours`); scripts under 1024 characters are never cached; inline scripts get no disk cache and no background compile (`kInlineScriptCache` and `kPrecompileInlineScripts` disabled by default); any V8 version change, including the patch number in most weekly security updates, invalidates JS and Wasm code caches; local compile hints apply only to classic scripts (verify/09). HTML-17.
- zstd content encoding: Chrome 123; Baseline newly available 2026-02-11. Encoders must keep the window at 8 MB or less (RFC 9659) (verify/02, verify/16 group 03). HTML-23.
- `Cache-Control: immutable`: Chromium has no support (BCD `false`); normal reloads in Chrome already skip revalidation of fresh subresources. HTML-21 does not use it (verify/04, verify/16 group 03).
- `Document-Policy: expect-no-linked-resources`: Chrome 134 (chromestatus 5202800863346688, 15-gaps-round-2, unchecked). No rule uses it: dropped as niche (see the crosswalk).
- Lighthouse 13 removed the `preload-fonts` and `uses-rel-preload` audits (HTML-12 says so without a version) and the `third-party-facades` audit, so no current tool flags a missing facade (HTML-18); the cache insight ID is `cache-insight` (verify/16 group 01, group 03, group 05).
