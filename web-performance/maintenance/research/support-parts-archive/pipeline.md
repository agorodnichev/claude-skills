Facts that pipeline.md states without a version (for support.md §C, if the writer wants them on record):

- Chromium intensive wake-up throttling: a fully loaded page that is hidden and silent gets one wake-up per minute for timer chains (chain count 5 or more) after 60 s hidden (`kIntensiveWakeUpThrottling_GracePeriodSecondsLoaded_Default`); 5 minutes for pages that were still loading; hidden-page timers align to 1 s after 10 s. An open WebSocket does not exempt the page (verify/06). pipeline.md §D and §H `memory`.
- Chromium tight mode: until `<body>` is attached, low-priority requests start only while fewer than two requests are in flight; from Chrome 117 the first 5 large images start at Medium priority (web.dev fetch-priority; verify/01). pipeline.md §H `network`.
- The network service runs in its own utility process by default; only Android (and `--single-process`) run it in the browser process (verify/01 run2-new). pipeline.md §A.
- `requestAnimationFrame` in dedicated workers: Chrome 69 (BCD `api.DedicatedWorkerGlobalScope.requestAnimationFrame`); not in nested workers in Chromium (verify/01 run2-new, verify/06). pipeline.md §A.
- Layerize runs on the renderer main thread (`PaintArtifactCompositor::Update()`), not on the compositor thread (verify/01 run2-new). pipeline.md §A.
- DevTools insights: `devtools-frontend` `main` exports 19 insights (`Models.ts`); chrome-devtools-mcp 1.10.1 lists only insights whose state is not `pass`, and never lists `SlowCSSSelector`, because MCP traces do not enable the selector-stats category. The MCP trace summary prints LCP (with subparts), INP and CLS, and no FCP, TBT, frame or GPU data (verify/14; 15-gaps-round-2, unchecked for the frame and GPU part). pipeline.md §I and §H `gpu-draw`.
- LCP candidate rules in Chromium (16-explore-fast-batch-03, unchecked): elements with opacity 0 are ignored (Chrome 86), elements that cover the whole viewport (Chrome 88), images under 0.05 bits of image data per displayed pixel (Chrome 112), transparent text (Chrome 130). pipeline.md §G.
